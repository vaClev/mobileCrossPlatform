## 2. Работа с переводами в проекте

```markdown
# Локализация (переводы) в проекте lesson0

Переводы организованы с помощью механизма Qt Linguist.  
Исходные строки пишутся на английском, перевод на русский содержится в скомпилированном файле `.qm`.

## Файлы переводов

- Исходные файлы переводов: `i18n/applesson0_en.ts` и `i18n/applesson0_ru.ts`
- Скомпилированный файл перевода: `applesson0_ru.qm` (лежит в корне проекта)
- Ресурсный путь в приложении: `:/i18n/applesson0_ru.qm`

## Генерация .qm-файла

### Автоматически (при сборке под Windows Desktop)

- Когда вы собираете проект с десктопным комплектом (`Desktop Qt 6.8.3 MinGW 64-bit`),
  CMake автоматически запускает `lupdate` и `lrelease`, обновляя `.ts`-файлы из исходников и создавая
  свежий `applesson0_ru.qm` в корне проекта.
- **Достаточно один раз собрать проект под Windows** перед Android-сборкой, чтобы файл появился.


### Вручную (если Desktop-кит недоступен)

Из папки `lesson0` выполните в терминале:

```bash
C:\Qt\6.8.3\mingw_64\bin\lupdate.exe . -ts i18n/applesson0_ru.ts
C:\Qt\6.8.3\mingw_64\bin\lrelease.exe i18n/applesson0_ru.ts -qm applesson0_ru.qm

----

Редактирование перевода
Для перевода строк на русский язык используйте Qt Linguist:
```
1. Запустите linguist из десктопной версии Qt (например, C:\Qt\6.8.3\mingw_64\bin\linguist.exe).

2. Откройте файл i18n/applesson0_ru.ts.

3. В левой колонке вы увидите исходные строки на английском.
   В правой – поле для ввода перевода.

4. Переведите все нужные строки и сохраните файл (Ctrl+S).

5. После этого снова соберите проект (или вручную выполните lrelease), чтобы обновить applesson0_ru.qm.
```

### Как добавить новый язык
```
Создайте новый .ts-файл, например i18n/applesson0_de.ts.

Добавьте его в qt_add_translations (в CMakeLists.txt) и пересоберите проект на Windows.

Отредактируйте перевод в Qt Linguist.

Добавьте соответствующий qt_add_resources для нового .qm-файла.

Доработайте логику в LanguageManager для поддержки нового языка.
```
