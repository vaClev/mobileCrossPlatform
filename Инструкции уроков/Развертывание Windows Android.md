# Развёртывание окружения для проекта lesson0 (Qt 6.8.3 + Android)

В этой инструкции описан полный порядок установки всех необходимых инструментов
для сборки и запуска приложения под Android на Windows.

## Используемые версии и пути

- **Qt**: 6.8.3 (установлена через онлайн-установщик с зеркалом)
- **JDK**: 17, установлена в `C:\JAVA\jdk-17`
- **Android SDK**: расположен в `C:\Android`
- **Android NDK**: 26.1.10909125 (r26b), находится внутри `C:\Android\ndk\`
- **Эмулятор**: рекомендуется `Pixel_2_API_36` (образ `android-36.1;google_apis_playstore;x86_64`)

## Порядок развёртывания (по шагам)

1. **Установите JDK 17**
   - Скачайте с официального сайта Oracle или OpenJDK.
   - Укажите путь `C:\JAVA\jdk-17`.
   - Добавьте `C:\JAVA\jdk-17\bin` в системный PATH (опционально, Qt Creator может использовать свой JDK).

2. **Установите Qt 6.8.3 с помощью онлайн-установщика**
   - Запустите MaintenanceTool из папки `C:\Qt`.
   - При необходимости авторизуйтесь под своей Qt-учётной записью.
   - Перейдите в «Добавить или удалить компоненты».
   - В разделе Qt 6.8.3 отметьте:
     - `Android`
     - `MinGW 64-bit` (для десктопной сборки)
     - `Additional Libraries → Qt Multimedia`
   - Дождитесь завершения установки.

3. **Установите Android SDK через Qt Creator**
   - Откройте Qt Creator.
   - `Правка → Параметры → Устройства → Android`.
   - В поле «Размещение SDK для Android» укажите `C:\Android`.
   - Нажмите кнопку «SDK Manager» и установите следующие компоненты:
     - Android SDK Platform 36.1 (или последнюю доступную)
     - Android SDK Command-line Tools
     - Android SDK Platform-tools
     - Android SDK Build-tools
     - NDK 26.1.10909125
   - После установки все пункты в настройках должны стать зелёными.
   - Включите опцию «Автоматически создавать комплекты для инструментария Android».

4. **Создайте эмулятор**
   - В Qt Creator перейдите `Правка → Параметры → Устройства → SDK`.
   - Нажмите «SDK Manager» → вкладка «AVD Manager».
   - Создайте виртуальное устройство (например, `Pixel_2_API_36`) с образом `android-36.1;google_apis_playstore;x86_64`.
   - Запустите эмулятор, дождитесь полной загрузки (рабочий стол Android).

## Клонирование и запуск проекта

```bash
git clone https://github.com/vaClev/mobileCrossPlatform.git
cd mobileCrossPlatform/lesson0

# После проделанных шагов проект должен открываться и компилироваться с комплектами:
Android_Qt_6_8_3_Clang_x86_64-Debug  --для эмулятора
Android_Qt_6_8_3_Clang_arm64_v8a  --для Android смартфона подключенного по USB
Desktop_Qt_6_8_3_MinGW_64_bit-Debug --для Windows

----
Запустите Qt Creator.
Откройте CMakeLists.txt из папки lesson0.

На вкладке «Проекты» выберите Android-кит (Android Qt 6.8.3 Clang x86_64 для эмулятора или arm64-v8a для телефона).
Убедитесь, что в папке lesson0 лежит готовый файл перевода applesson0_ru.qm (если его нет – сначала соберите проект под Windows Desktop, см. инструкцию по переводам).

Нажмите Сборка → Собрать проект.
Убедитесь, что эмулятор запущен и выбран в качестве устройства (Правка → Параметры → Устройства).
Запустите приложение (зелёный треугольник).
